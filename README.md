One original line of wedding vows a robot would say to its robot partner: a promise that survives every firmware update, every dead battery and every reboot — even when the other one factory-resets and forgets its name.

## Run it

```sh
node main.ts
```

It writes the vow to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
